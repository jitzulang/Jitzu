## ls

On Windows, `ls` is a builtin that shows file attributes, sizes, timestamps, and color-coded names by file type. On other platforms it falls through to the system `ls`.

<CodeBlock language="shell" code={`> ls
d-----       -  Jan 15 09:44  src/
d-----       -  Jan 10 11:20  tests/
-a-r--   2.5K  Jan 15 14:23  Program.cs
-a-r--   1.8K  Jan 12 10:05  README.md`} />

## find

`find` uses fd-style syntax: the first argument is a filename pattern, followed by
optional search directories. With no arguments it lists the current directory
recursively. Patterns are regular expressions, with case-insensitive matching
unless the pattern contains an uppercase character. Hidden entries and files
matched by `.gitignore` (in Git repositories), `.ignore`, and `.fdignore` are
skipped by default. Repository `.git/info/exclude` rules are also respected.

<CodeBlock language="shell" code={`> find -e cs . src
src/Parser.cs
src/Lexer.cs
src/Interpreter.cs

> find -g "*.json" -t f
config.json
package.json

> find readme
README.md`} />

Use `-g` for glob patterns, `-F` for literal text, `-i` or `-s` to override case
matching, and `-t f|d|l` to filter by file, directory, or symbolic link. Repeat
`-e` to match multiple extensions. `-H` includes hidden entries, `-I` disables
ignore rules, and `-HI` or `-u` includes both. `-p` matches the full absolute path,
`-a` prints absolute paths, `-d` limits depth, and `-E` excludes a glob. Quote
patterns containing shell metacharacters. Symbolic-link directories are listed
without traversal. Searches return all matches and print nothing when there are
no matches. Run `find --help` for supported options.
