# Installation

Jitzu is distributed as a single standalone binary — `jz` — that serves as both the script interpreter and the interactive shell. Download the self-contained build for your platform — it bundles the .NET runtime, so it works on any machine with no prerequisites.

<DownloadButtons />

## Package Managers

### Windows (WinGet)

WinGet is included with current versions of Windows 10 and Windows 11.

<CodeBlock language="powershell" code={`winget install --id JitzuLang.Jitzu --exact`} />

### Windows (Scoop)

<CodeBlock language="powershell" code={`scoop bucket add jitzu https://github.com/jitzulang/jitzu
scoop install jz`} />

### Arch Linux

The recommended Arch installation uses Jitzu's signed pacman repository. Download
the public signing key, inspect its fingerprint, and compare it with the
[published fingerprint and repository details](https://github.com/jitzulang/jitzu/blob/main/packaging/arch/REPOSITORY.md#installation)
before trusting it:

<CodeBlock language="bash" code={`curl -O https://packages.jitzu.dev/arch/x86_64/jitzu-signing-key.asc
gpg --show-keys --with-fingerprint jitzu-signing-key.asc`} />

After confirming the full fingerprint is
`A239257C5BF7E6D68EF823C48E1ADE54F78F6A5B`, add and locally trust the key:

<CodeBlock language="bash" code={`sudo pacman-key --add jitzu-signing-key.asc
sudo pacman-key --lsign-key A239257C5BF7E6D68EF823C48E1ADE54F78F6A5B`} />

Add this repository entry to `/etc/pacman.conf`:

<CodeBlock language="ini" code={`[jitzu]
SigLevel = PackageRequired DatabaseRequired
Server = https://packages.jitzu.dev/arch/$arch`} />

Then install Jitzu and receive future updates with pacman:

<CodeBlock language="bash" code={`sudo pacman -Syu jz-bin`} />

The repository supports x86_64. You can also install from the
[AUR](https://aur.archlinux.org/packages/jz-bin) or download a standalone package
from the [GitHub releases page](https://github.com/jitzulang/jitzu/releases). The
standalone package requires manual installation and does not update through
`pacman -Syu`.

## Self-Contained Binary

The self-contained binary bundles the .NET runtime, so it works on any machine with no
prerequisites. This is the easiest way to get started without a package manager.

### Windows

Download `jitzu-win-x64.zip` from the [latest GitHub release](https://github.com/jitzulang/jitzu/releases/latest). The following PowerShell commands extract it to a user-owned application directory and add that directory to your persistent user PATH without requiring administrator access.

<CodeBlock language="powershell" code={`$dest = Join-Path $env:LOCALAPPDATA "Programs\\Jitzu"
New-Item -ItemType Directory -Force -Path $dest | Out-Null
Expand-Archive .\\jitzu-win-x64.zip -DestinationPath $dest -Force

$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
$pathEntries = @($userPath -split ";" | Where-Object { $_ })
if ($pathEntries -notcontains $dest) {
    [Environment]::SetEnvironmentVariable(
        "Path",
        ($pathEntries + $dest) -join ";",
        "User"
    )
}`} />

Restart your terminal after updating PATH, then run `jz --version` to verify the installation.

### macOS

Download `jitzu-osx-arm64.zip` (Apple Silicon) or `jitzu-osx-x64.zip` (Intel) from the [latest release](https://github.com/jitzulang/jitzu/releases/latest).

<CodeBlock language="bash" code={`unzip jitzu-osx-arm64.zip
sudo mv jz /usr/local/bin/
chmod +x /usr/local/bin/jz`} />

### Linux

Download `jitzu-linux-x64.zip` from the [latest release](https://github.com/jitzulang/jitzu/releases/latest).

<CodeBlock language="bash" code={`unzip jitzu-linux-x64.zip
sudo mv jz /usr/local/bin/
chmod +x /usr/local/bin/jz`} />

## Self-Update

Jitzu can update itself:

<CodeBlock language="bash" code={`jz upgrade`} />

## Build from Source

Jitzu requires the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) to build from source.

<CodeBlock language="bash" code={`git clone https://github.com/jitzulang/jitzu.git
cd jitzu
dotnet build
dotnet run --project Jitzu.Shell -- --help
dotnet run --project Jitzu.Shell`} />

## Verify Installation

Check the interpreter is on your PATH:

<CodeBlock language="bash" code={`jz --version
# jz v0.2.0`} />

Then launch the shell:

<CodeBlock language="shell" code={`jz v0.2.0

• runtime    : 10.0.0
• config     : ~/.jitzu/config.jz
• platform   : Unix

Type \`help\` to get started.

> 1 + 1
2`} />
